# dtm-tos

**dtm-tools** — это консольная утилита на Си, предназначенная для автоматического построения цифровой модели рельефа (ЦМР) методом триангуляции Делоне и её интерактивной визуализации в 3D-сцене.

##  Особенности проекта
* **Высокая производительность:** Написан на чистом Си (стандарт C99) без избыточных тяжелых библиотек.
* **Полноценная триангуляция:** Реализован инкрементный геометрический алгоритм Боуэра-Ватсона (Bowyer-Watson) для построения нерегулярной сети треугольников (TIN) по хаотично распределенным точкам.
* **Автоматическое центрирование:** Утилита сама рассчитывает габариты рельефа и масштабирует модель, чтобы ландшафт любого размера встал ровно по центру экрана.
* **Гипсометрическая окраска:** Вершины треугольников динамически окрашиваются в зависимости от их высоты Z, создавая наглядный цветовой градиент.
* **Интерактивное управление:** Возможность вращать рельеф в 3D-пространстве под любым углом с клавиатуры.

## Системные требования и зависимости
Программа разработана для Linux-окружения (включая **WSL2** под Windows). Для компиляции и графики необходимы:
* Компилятор `gcc` (с поддержкой C99)
* Система сборки `CMake` (версии 3.10 и выше)
* Графические библиотеки: `GLFW3` и `OpenGL`

Установка всех необходимых пакетов одной командой (для Ubuntu/Debian/WSL):
```bash
sudo apt update && sudo apt install -y build-essential cmake libglfw3-dev libgl1-mesa-dev libglu1-mesa-dev
```

## Сборка проекта
Сборка проекта стандартизирована с помощью CMake:

```bash
# 1. Создайте папку для сборки и перейдите в нее
mkdir build && cd build

# 2. Сгенерируйте конфигурационные файлы и скомпилируйте утилиту
cmake ..
make
```

## Использование
Запуск программы осуществляется через терминал с обязательной передачей пути к вашему CSV-файлу в качестве аргумента:

```bash
./dtm_viewer ../data/test_csv_file.csv
```

### Формат входного файла CSV
Файл должен содержать строку-заголовок (`X,Y,Z`), а координаты точек должны быть разделены запятыми. Пример:
```text
X,Y,Z
10.5,24.0,5.9
45.2,11.8,12.4
112.1,85.6,22.1
```

##Управление в 3D-окне
* **Стрелки Влево / Вправо:** Поворот рельефа вокруг вертикальной оси.
* **Стрелки Вверх / Вниз:** Наклон сцены для просмотра под углом.
* **Клавиша ESC:** Быстрый и безопасный выход из программы с полной очисткой памяти.
